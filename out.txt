# Carelio (kine) Code Review

## Overall Score: 3/10

This is an early-stage learning project with a reasonable package layout, but it has confirmed compile errors, data-losing bugs, zero security, hardcoded credentials committed, and no meaningful tests. It is not production-ready.

---

## What's Good

- **Layered package structure**: Controller -> Service -> Repository -> Entity with DTOs and MapStruct mappers. Correct idea.
- **Soft delete pattern** attempted via `BaseEntity.deleted` flag.
- **Validation annotations** on some request DTOs (`@NotBlank`, `@Email`).
- **Duplicate checks** on user creation (email/username).
- **springdoc/Swagger** integrated for API documentation.
- **Maven wrapper** included for reproducible builds.

---

## Critical Bugs (will crash or lose data)

### BUG 1: `Equipment.java` does not compile

`Equipment.java` imports `com.amigoscode.carelio.serviceOrder.entity.ServiceOrder` but the actual package is `com.amigoscode.carelio.service_order.entity`. The project will not compile. `UserAddressInformation.java` and `Worker.java` use the correct import.

### BUG 2: `EquipmentService.delete()` does not persist the soft delete

```java
@Transactional
public void delete(Long id) {
    Equipment equipment = getById(id);
    equipment.setDeleted(true);
    equipment.setUpdatedAt(LocalDateTime.now());
    // Missing: equipmentRepository.save(equipment)
}
```

The entity is fetched, mutated in memory, and discarded. The `getById()` call goes through a class-level `readOnly = true` method, making dirty-checking unreliable. The delete silently does nothing.

### BUG 3: `EquipmentCategoryService` writes inside `readOnly = true`

The class is annotated `@Transactional(readOnly = true)` but `create()`, `update()`, and `delete()` methods have no `@Transactional` override. Writes will either silently fail or throw depending on the driver/DB config.

### BUG 4: `EquipmentCategoryController` has no URL path

```java
@RestController("/equipment-category")   // This sets the bean name, NOT the URL
@RequestMapping                          // Empty = maps to /
```

All methods map to `/`, `/{id}`, etc. This collides with other controllers. Should be `@RequestMapping("/equipment-categories")`.

### BUG 5: JPA relationship cardinality mismatches

- **Worker <-> ServiceOrder**: `ServiceOrder` has `@ManyToOne` to `Worker` (many orders per worker), but `Worker` has `@OneToOne(mappedBy = "assignedWorker")`. Should be `@OneToMany`.
- **UserAddressInformation <-> ServiceOrder**: `ServiceOrder` has `@ManyToOne` to address, but `UserAddressInformation` has `@OneToOne(mappedBy = ...)`. Should be `@OneToMany`.

---

## Security Flaws

### SEC 1: Hardcoded database credentials in version control

```properties
spring.datasource.username=postgres
spring.datasource.password=123456
```

Credentials must never be committed. Use environment variables or Spring profiles with externalized secrets.

### SEC 2: No authentication or authorization

No Spring Security dependency, no filters, no token validation. Every endpoint is wide open: anyone can create users, assign admin roles, delete rooms.

### SEC 3: `grantedBy` is a user-supplied query param with no verification

The role assignment endpoint takes `grantedBy` as a raw `Long` query parameter. No check that the caller is actually that user or has permission to grant roles. IDOR / privilege escalation vector.

### SEC 4: `create-drop` DDL strategy

```properties
spring.jpa.hibernate.ddl-auto=create-drop
```

Drops and recreates the entire database schema every time the app restarts. All data is destroyed.

---

# Carelio v2 Code Review

## Overall Score: 7/10

A solid improvement over v1, with all 6 domains fully implemented, correct layering, proper error handling, and no compile errors. However, it still lacks authentication, tests, and several production concerns.

---

## What's Good (improvements over v1)

### Architecture (was 4/10, now 8/10)

- **Service returns DTOs, not entities.** Controllers are thin and only know about DTOs. The mapper lives in the service layer where it belongs.
- **Global `@ControllerAdvice`** handles all exceptions with proper HTTP status codes: 404 for not found, 409 for duplicates, 422 for business rules, 400 for validation errors.
- **Custom exception hierarchy** (`ResourceNotFoundException`, `DuplicateResourceException`, `BusinessRuleException`) replaces scattered `RuntimeException` throws.
- **Consistent `@Transactional` usage**: class-level `readOnly = true` with `@Transactional` overrides on write methods. Every service follows this pattern.
- **`@Valid` on every `@RequestBody`** — validation annotations actually fire.
- **No duplicate MapStruct beans** — `componentModel = "spring"` only, no manual `Mappers.getMapper()`.
- **No stray imports** — no cross-module import leaks.
- **All `@RequestMapping` paths are correct** — no bean-name-as-path mistakes.
- **All `@RequestBody` annotations present** where needed.
- **All `save()` calls present** — soft delete actually persists.

### Database Design (was 3/10, now 7/10)

- **`Room` has an `owner_id` FK** to `User` — rooms belong to a specific user/household.
- **`ServiceOrder` has a `customer_id` FK** — direct ownership, not indirect via address.
- **`UserAuthProvider` has a `user_id` FK** — properly connected to the user.
- **Roles as `@ElementCollection`** — no over-engineered `Role` entity for 3 enum values.
- **`BaseEntity.deleted` is `boolean` (primitive)** — no null ambiguity.
- **`EquipmentCategory` is a standalone entity without `BaseEntity`** — reference data doesn't need soft delete or audit timestamps.
- **`WorkerSkill` is a standalone entity without `BaseEntity`** — join table with no soft delete.
- **Correct JPA cardinalities** — `ServiceOrder` has `@ManyToOne` to Worker, and Worker doesn't declare the inverse (avoids the OneToOne vs OneToMany mismatch).
- **Consistent `findByIdAndDeletedFalse`** — soft-delete is respected on both list and get-by-id queries.

### Business Logic (was 1/10, now 7/10)

- **All 6 domains are fully implemented** with REST endpoints: User, Room, Equipment, Worker, ServiceOrder, Payment.
- **Full repair workflow**: create order (PENDING) -> assign worker (ASSIGNED) -> start work (IN_PROGRESS) -> complete or cancel.
- **Status transition validation** with a state machine in `ServiceOrderService.validateTransition()`.
- **Worker availability management** — worker goes BUSY when assigned, AVAILABLE when order completes/cancels.
- **Job counter** increments on order completion.
- **Pagination** on all list endpoints via `Pageable`.
- **Filter endpoints**: by room, by category, by owner, by customer, by worker, by status.
- **Address management API** — users can add addresses.
- **Role management** — add and remove roles from users.
- **Worker skill management** — add and remove skills with duplicate detection.
- **Duplicate detection** on user email/username, category name, transaction reference.
- **Business rule guards**: can't delete room with equipment, can't delete category with equipment, can't assign worker to completed order, can't pay for cancelled order.

### Configuration (was 0/10, now 6/10)

- **No hardcoded credentials** — uses `${DB_URL}`, `${DB_USER}`, `${DB_PASSWORD}` env vars.
- **Profile separation** — `application.properties` (shared) + `application-dev.properties` (local dev defaults).
- **`ddl-auto=update`** instead of `create-drop` — data survives restarts.
- **`show-sql` only in dev profile**.

---

## What's Still Missing (honest flaws)

### Security: 0/10 (unchanged)

- **No Spring Security.** All endpoints are still wide open. Anyone can create users, assign admin roles, delete orders, and process payments.
- **No authentication mechanism** — no JWT, no session, no OAuth2.
- **No authorization** — no `@PreAuthorize`, no role-based access control on endpoints.
- **`passwordHash` field exists on `User` but is never set or validated.** It's a placeholder that does nothing.
- **No CORS configuration.**
- This is the single biggest gap. Without auth, none of the business logic access controls matter.

### Testing: 0/10 (unchanged)

- **Still only one empty `contextLoads` test.** Zero unit tests for services, mappers, controllers. Zero integration tests.
- **No test configuration** — no H2 in-memory database for tests, no Testcontainers, no `application-test.properties`.
- **No MockMvc tests** for controllers.
- **Business logic like `validateTransition()` is critical and completely untested.**

### DevOps: 1/10

- **No CI/CD pipeline.**
- **No Dockerfile or docker-compose.**
- **No database migration tool** — Hibernate `ddl-auto=update` is better than `create-drop` but is not production-grade. Column renames, data migrations, and rollbacks require Flyway or Liquibase.

### API Design Gaps

- **No API versioning** — paths are `/api/...` but no `/api/v1/...` prefix for future evolution.
- **No rate limiting.**
- **No request/response logging or correlation IDs.**
- **Payment is simplistic** — marks as COMPLETED immediately on creation. Real payments need async processing, webhook callbacks, idempotency keys.
- **No search by name/keyword** on any entity — only filter by ID or enum.
- **`EquipmentCategory` list is not paginated** — will be a problem if categories grow (unlikely but inconsistent with the rest).
- **Multiple `@GetMapping` with `params =` on the same controller** could cause ambiguity if a client sends multiple query params simultaneously.

### Data Integrity Concerns

- **No database-level indexes** beyond PKs and unique constraints. Queries like `findAllByCustomerIdAndDeletedFalse` will table-scan without an index on `(customer_id, deleted)`.
- **No optimistic locking** (`@Version`) — concurrent updates will silently overwrite each other.
- **`UserAddress` has soft delete** but addresses are looked up by `findById` (without deleted check) in `ServiceOrderService.create()` — inconsistent.
- **Cascade on `User.addresses` is `ALL` with `orphanRemoval`** — deleting a user hard-deletes their addresses, which may still be referenced by service orders.

### Code Structure

- **Cross-module service dependencies** are deep: `ServiceOrderService` depends on `UserService`, `EquipmentService`, `WorkerService`, and `UserAddressRepository`. This creates a wide fan-out. In a larger codebase, this should be mediated through events or a facade.
- **No DTO for detailed views** — e.g., getting a room doesn't include its equipment list (only a count). Getting a user doesn't include their addresses. Some endpoints may want richer responses.

1. **Add Spring Security + JWT authentication** — this unlocks actual access control.
2. **Write tests** — unit tests for services (especially `validateTransition`, duplicate checks, business rules), MockMvc for controllers.
3. **Add `@Version` for optimistic locking** on entities that support concurrent updates.
4. **Add database indexes** on commonly queried FK columns.
5. **Fix `UserAddress` soft-delete inconsistency** in `ServiceOrderService`.
6. **Add Flyway** for schema migrations.

8. **Add CI pipeline** (GitHub Actions or similar).

package com.carelio.common.exception;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.time.LocalDateTime;
import java.util.HashMap;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(ResourceNotFoundException ex) {
        return buildResponse(HttpStatus.NOT_FOUND, ex.getMessage());
    }

    @ExceptionHandler(DuplicateResourceException.class)
    public ResponseEntity<ErrorResponse> handleDuplicate(DuplicateResourceException ex) {
        return buildResponse(HttpStatus.CONFLICT, ex.getMessage());
    }

    @ExceptionHandler(BusinessRuleException.class)
    public ResponseEntity<ErrorResponse> handleBusinessRule(BusinessRuleException ex) {
        return buildResponse(HttpStatus.UNPROCESSABLE_ENTITY, ex.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidation(MethodArgumentNotValidException ex) {
        Map<String, String> fieldErrors = new HashMap<>();
        for (FieldError error : ex.getBindingResult().getFieldErrors()) {
            fieldErrors.put(error.getField(), error.getDefaultMessage());
        }
        Map<String, Object> body = new HashMap<>();
        body.put("timestamp", LocalDateTime.now());
        body.put("status", HttpStatus.BAD_REQUEST.value());
        body.put("errors", fieldErrors);
        return ResponseEntity.badRequest().body(body);
    }

    private ResponseEntity<ErrorResponse> buildResponse(HttpStatus status, String message) {
        ErrorResponse body = new ErrorResponse(
                LocalDateTime.now(),
                status.value(),
                status.getReasonPhrase(),
                message
        );
        return ResponseEntity.status(status).body(body);
    }

    public record ErrorResponse(LocalDateTime timestamp, int status, String error, String message) {}
}

                && categoryRepository.existsByName(request.getName())) {

        EquipmentCategory category = findOrThrow(id);
        if (equipmentRepository.existsByCategoryId(id)) {
            throw new BusinessRuleException("Cannot delete category that has equipment assigned");
        }
        categoryRepository.delete(category);
    }

                .orElseThrow(() -> new ResourceNotFoundException("EquipmentCategory", id));

    private final ServiceOrderMapper orderMapper;
    private final UserService userService;

    private final UserAddressRepository addressRepository;

    }

        Page<ServiceOrder> page = orderRepository.findAllByAssignedWorkerIdAndDeletedFalse(workerId, pageable);
        return PageResponse.of(page, orderMapper.toResponseList(page.getContent()));
    }

    public PageResponse<ServiceOrderResponse> getByStatus(OrderStatus status, Pageable pageable) {
        Page<ServiceOrder> page = orderRepository.findAllByStatusAndDeletedFalse(status, pageable);
        return PageResponse.of(page, orderMapper.toResponseList(page.getContent()));
    }

    public ServiceOrderResponse getById(Long id) {
        return orderMapper.toResponse(findActiveOrThrow(id));
    }

    @Transactional
    public ServiceOrderResponse create(CreateServiceOrderRequest request) {
        User customer = userService.findActiveOrThrow(request.getCustomerId());
        Equipment equipment = equipmentService.findActiveOrThrow(request.getEquipmentId());

        UserAddress address = null;
        if (request.getAddressId() != null) {
            address = addressRepository.findById(request.getAddressId())
                    .orElseThrow(() -> new ResourceNotFoundException("UserAddress", request.getAddressId()));
        }

        ServiceOrder order = ServiceOrder.builder()
                .title(request.getTitle())
                .description(request.getDescription())
                .status(OrderStatus.PENDING)
                .serviceTypes(request.getServiceTypes())
                .customer(customer)
                .equipment(equipment)
                .address(address)
                .build();

        return orderMapper.toResponse(orderRepository.save(order));
    }

    @Transactional
    public ServiceOrderResponse assignWorker(Long orderId, AssignWorkerRequest request) {
        ServiceOrder order = findActiveOrThrow(orderId);

        if (TERMINAL_STATUSES.contains(order.getStatus())) {
            throw new BusinessRuleException("Cannot assign worker to a " + order.getStatus() + " order");
        }

        Worker worker = workerService.findActiveOrThrow(request.getWorkerId());
        if (worker.getStatus() != WorkerStatus.AVAILABLE) {
            throw new BusinessRuleException("Worker is not available (current status: " + worker.getStatus() + ")");
        }

        order.setAssignedWorker(worker);
        order.setStatus(OrderStatus.ASSIGNED);
        worker.setStatus(WorkerStatus.BUSY);

        return orderMapper.toResponse(orderRepository.save(order));
    }

    @Transactional
    public ServiceOrderResponse updateStatus(Long orderId, UpdateOrderStatusRequest request) {
        ServiceOrder order = findActiveOrThrow(orderId);
        OrderStatus current = order.getStatus();
        OrderStatus next = request.getStatus();

        validateTransition(current, next);

        order.setStatus(next);

        if (next == OrderStatus.COMPLETED || next == OrderStatus.CANCELLED) {
            if (order.getAssignedWorker() != null) {
                order.getAssignedWorker().setStatus(WorkerStatus.AVAILABLE);
                if (next == OrderStatus.COMPLETED) {
                    order.getAssignedWorker().setTotalJobs(
                            order.getAssignedWorker().getTotalJobs() + 1);
                }
            }
        }

        return orderMapper.toResponse(orderRepository.save(order));
    }

    @Transactional
    public void cancel(Long orderId) {
        ServiceOrder order = findActiveOrThrow(orderId);
        if (TERMINAL_STATUSES.contains(order.getStatus())) {
            throw new BusinessRuleException("Order is already " + order.getStatus());
        }
        order.setStatus(OrderStatus.CANCELLED);
        if (order.getAssignedWorker() != null) {
            order.getAssignedWorker().setStatus(WorkerStatus.AVAILABLE);
        }
        order.setDeleted(true);
        orderRepository.save(order);
    }

    private void validateTransition(OrderStatus current, OrderStatus next) {
        boolean valid = switch (current) {
            case PENDING -> next == OrderStatus.ASSIGNED || next == OrderStatus.CANCELLED;
            case ASSIGNED -> next == OrderStatus.IN_PROGRESS || next == OrderStatus.CANCELLED;
            case IN_PROGRESS -> next == OrderStatus.COMPLETED || next == OrderStatus.CANCELLED;
            case COMPLETED, CANCELLED -> false;
        };
        if (!valid) {
            throw new BusinessRuleException(
                    "Invalid status transition: " + current + " -> " + next);
        }
    }

                .orElseThrow(() -> new ResourceNotFoundException("ServiceOrder", id));

        List<UserResponse> content = userMapper.toResponseList(page.getContent());

    }

    public UserResponse getById(Long id) {
        User user = findActiveOrThrow(id);
        return userMapper.toResponse(user);

    @Transactional
    public UserResponse create(CreateUserRequest request) {
        if (userRepository.existsByEmail(request.getEmail())) {
            throw new DuplicateResourceException("Email already exists: " + request.getEmail());
        }
        if (userRepository.existsByUsername(request.getUsername())) {
            throw new DuplicateResourceException("Username already exists: " + request.getUsername());
        }

        User user = userMapper.toEntity(request);
        user.setStatus(UserStatus.ACTIVE);
        user.setRoles(Set.of(RoleCode.CUSTOMER));
        User saved = userRepository.save(user);
        return userMapper.toResponse(saved);
    }

    @Transactional
    public UserResponse update(Long id, UpdateUserRequest request) {
        User user = findActiveOrThrow(id);

        if (request.getUsername() != null) {
            if (!user.getUsername().equals(request.getUsername())
                    && userRepository.existsByUsername(request.getUsername())) {
                throw new DuplicateResourceException("Username already exists: " + request.getUsername());
            }
            user.setUsername(request.getUsername());
        }
        if (request.getAvatarUrl() != null) user.setAvatarUrl(request.getAvatarUrl());
        if (request.getPhoneNumber() != null) user.setPhoneNumber(request.getPhoneNumber());

        return userMapper.toResponse(userRepository.save(user));
    }

    @Transactional
    public void softDelete(Long id) {
        User user = findActiveOrThrow(id);
        user.setStatus(UserStatus.INACTIVE);
        user.setDeleted(true);
        userRepository.save(user);
    }

    @Transactional
    public UserResponse addRole(Long id, RoleCode role) {
        User user = findActiveOrThrow(id);
        user.getRoles().add(role);
        return userMapper.toResponse(userRepository.save(user));
    }

    @Transactional
    public UserResponse removeRole(Long id, RoleCode role) {
        User user = findActiveOrThrow(id);
        user.getRoles().remove(role);
        return userMapper.toResponse(userRepository.save(user));
    }

    public UserAddressResponse addAddress(Long userId, CreateUserAddressRequest request) {

                .user(user)
                .city(request.getCity())
                .district(request.getDistrict())
                .ward(request.getWard())
                .addressLine(request.getAddressLine())
                .defaultAddress(request.isDefaultAddress())
                .build();
        return userMapper.toAddressResponse(userAddressRepository.save(address));
    }

import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@RequiredArgsConstructor
@Transactional(readOnly = true)
public class WorkerService {

    private final WorkerRepository workerRepository;
    private final WorkerSkillRepository workerSkillRepository;
    private final WorkerMapper workerMapper;
    private final UserService userService;
    private final EquipmentCategoryService categoryService;

    public PageResponse<WorkerResponse> getAll(Pageable pageable) {
        Page<Worker> page = workerRepository.findAllByDeletedFalse(pageable);
        List<WorkerResponse> content = workerMapper.toResponseList(page.getContent());
        return PageResponse.of(page, content);
    }

    public PageResponse<WorkerResponse> getAvailable(Pageable pageable) {
        Page<Worker> page = workerRepository.findAllByStatusAndDeletedFalse(
                WorkerStatus.AVAILABLE, pageable);
        List<WorkerResponse> content = workerMapper.toResponseList(page.getContent());
        return PageResponse.of(page, content);
    }

    public WorkerResponse getById(Long id) {
        return workerMapper.toResponse(findActiveOrThrow(id));
    }

    @Transactional
    public WorkerResponse create(CreateWorkerRequest request) {
        if (workerRepository.existsByUserId(request.getUserId())) {
            throw new DuplicateResourceException(
                    "Worker profile already exists for user: " + request.getUserId());
        }

        User user = userService.findActiveOrThrow(request.getUserId());
        user.getRoles().add(RoleCode.WORKER);

        Worker worker = Worker.builder()
                .user(user)
                .bio(request.getBio())
                .build();

        return workerMapper.toResponse(workerRepository.save(worker));
    }

    @Transactional
    public WorkerResponse update(Long id, UpdateWorkerRequest request) {
        Worker worker = findActiveOrThrow(id);

        if (request.getBio() != null) worker.setBio(request.getBio());
        if (request.getStatus() != null) worker.setStatus(request.getStatus());

        return workerMapper.toResponse(workerRepository.save(worker));
    }

    @Transactional
    public WorkerResponse addSkill(Long workerId, AddWorkerSkillRequest request) {
        Worker worker = findActiveOrThrow(workerId);
        EquipmentCategory category = categoryService.findOrThrow(request.getCategoryId());

        boolean duplicate = worker.getSkills().stream().anyMatch(s ->
                s.getSkillCode() == request.getSkillCode()
                        && s.getCategory().getId().equals(request.getCategoryId()));
        if (duplicate) {
            throw new DuplicateResourceException("Worker already has this skill for this category");
        }

        WorkerSkill skill = WorkerSkill.builder()
                .worker(worker)
                .skillCode(request.getSkillCode())
                .category(category)
                .yearsExperience(request.getYearsExperience())
                .skillLevel(request.getSkillLevel())
                .build();

        worker.getSkills().add(skill);
        return workerMapper.toResponse(workerRepository.save(worker));
    }

    @Transactional
    public WorkerResponse removeSkill(Long workerId, Long skillId) {
        Worker worker = findActiveOrThrow(workerId);
        boolean removed = worker.getSkills().removeIf(s -> s.getId().equals(skillId));
        if (!removed) {
            throw new ResourceNotFoundException("WorkerSkill", skillId);
        }
        return workerMapper.toResponse(workerRepository.save(worker));
    }

    public Worker findActiveOrThrow(Long id) {
        return workerRepository.findByIdAndDeletedFalse(id)
                .orElseThrow(() -> new ResourceNotFoundException("Worker", id));
    }

    public Worker findByUserIdOrThrow(Long userId) {
        return workerRepository.findByUserIdAndDeletedFalse(userId)
                .orElseThrow(() -> new BusinessRuleException(
                        "No worker profile found for user: " + userId));
    }
